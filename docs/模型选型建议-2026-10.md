### 线 B — Hermes Agent(跑自动化)

Hermes 内置 **34 个 provider**,老板问的 5 家全覆盖。

**最省事的 3 个 OAuth 登录**(不用申请 key):
```bash
hermes model          # 交互式选择器
# 选 nous / openai-codex / qwen-oauth / xai-oauth / minimax-oauth
```

**关键点**:
- `openai-codex` = 用 ChatGPT 订阅登录 → **买 ChatGPT Plus $20 就能给 Hermes 用**
- `qwen-oauth` = 阿里云账号 OAuth 登录 → **免费额度直接用**
- `kimi-coding` = `sk-kimi-` 开头的 key 会自动切到 `api.kimi.com/coding` → **Kimi 会员额度直接用**
- `anthropic` = `CLAUDE_CODE_OAUTH_TOKEN`(sk-ant-oat01...)可复用 Claude Code 的登录态

## 三、推荐方案

### 🥇 主力组合(推荐)

**vibe coding → Claude Code + Anthropic 订阅**
**Hermes → qwen-oauth(免费)或 openai-codex**

理由:
1. Claude Code 写代码质量目前仍第一,尤其多文件重构和长任务
2. Hermes 干活用便宜模型就够,Qwen OAuth 中文强、免费
3. 两条线用不同额度池,不互相挤

### 🥈 极致省钱组合

**vibe coding → Codex CLI + ChatGPT Plus $20**
**Hermes → qwen-oauth(完全免费)**

理由:Plus $20 有 GPT-6.1 Sol 15-160 请求/5小时,日常够用。
Hermes 用 Qwen 免费额度,老板在越南用 Qwen 也顺手。

### 🥉 性价比组合(中文场景)

**vibe coding → Kimi Code + Kimi 会员 Plus ¥99/月**
**Hermes → qwen-oauth**

理由:Kimi Plus 才 ¥79(年付折合),5 小时滚动窗口无周限额。
韩语/中文能力不错,K2.7 Code 专门强化过编程。

### ⚠️ 不推荐现在押注

- **Gemini 个人版** — 2026-06-18 后迁 Antigravity,还在变动期
- **DeepSeek** — 没有订阅,只有按量;便宜但要自己管额度
- **Qwen Token Plan 给 Lark Bot** — ToS 不允许

## 四、执行动作(老板点头就做)

```bash
# 1. 看 Hermes 现在能选哪些 provider 和模型
hermes model --refresh

# 2. 登录 Qwen OAuth(免费,推荐先做这个)
hermes model    # 选 Qwen OAuth

# 3. 登录 Codex(如果买了 ChatGPT Plus)
hermes model    # 选 OpenAI Codex

# 4. 配 fallback(主模型挂了自动切)
#    ~/.hermes/config.yaml
#    fallback_providers:
#      - provider: qwen-oauth
#        model: <某个模型>
```
