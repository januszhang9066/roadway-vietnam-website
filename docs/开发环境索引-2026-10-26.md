### ⚠️ 3. 根路径 `/` 301 循环(待修)

```
curl http://localhost:8080/
→ 301 → http://localhost:8080:8080/wp-admin/     ← 端口拼了两次
```

**根因**:`wp-config.php` 第 7 行
```php
$rw_parts = explode(':', $rw_host);
if (count($rw_parts) === 2 && $rw_parts[1] === $rw_parts[1]) {   // ← 恒真,死代码
    $rw_host = $rw_parts[0] . ':' . $rw_parts[1];                // ← 原样拼回,没去重
}
```
条件写成了自己跟自己比,恒为真,所以「去重」逻辑从未生效。
正确写法应该是判断 `$_SERVER['HTTP_HOST']` 里是否已含端口,
或者直接用 `$_SERVER['SERVER_NAME']` + `$_SERVER['SERVER_PORT']` 组合。

**影响**:本地根路径访问会跳到 wp-admin;生产环境如果 `siteurl` 配的是
`http://roadwayvn.com` 而请求带 www,也会有类似跳转问题。

### ⚠️ 4. 交付物 `|` 分隔解析 bug(仍未修)

`rw_list()` 只按换行分条,数据用 `|` 分隔时 6 条被并成 1 条。
官网 AGENTS.md 里已记下这个坑。
